## 💡 The Problem & Our Vision

### 🔴 The Problem
Global climate tracking relies heavily on autonomous, robotic ARGO profiling floats drifting through deep ocean currents. While these floats record vital telemetry data (salinity, temperature, pressure), the data is trapped inside massive, rigid **NetCDF files** and geospatial database tables. Marine scientists, policymakers, and researchers face a huge barrier: they must write programmatic queries or SQL models just to get basic insights.

### 🟢 Our Solution (FloatChat)
**FloatChat** democratizes ocean climate science. It acts as an intelligent natural-language wrapper over ARGO datasets. Users simply ask plain-language questions (e.g., *"Show me salinity trends in the Bay of Bengal"*), and our semantic engine instantly converts that into spatio-temporal queries, simultaneously rendering the results onto an interactive 4D/3D WebGL data visualization pipeline.

## 🛠️ Tech Stack & Systems Architecture

* **Frontend UI Dashboard:** Responsive HTML5, Flexbox/Grid Systems, and Semantic Layouts
* **Visuals & 3D Render Engines:** Custom CSS3, WebGL, and Three.js (for spat-temporal float trajectories)
* **AI & Parsing Logic:** JavaScript/Python multi-modal query translators 
* **Version Control & Hosting Infrastructure:** Git, GitHub & GitHub Pages continuous integration pipelines

---

## ✨ Key Features Built

* **Natural Language to Geospatial Mapping:** Converts organic text prompts directly into regional coordinate bounds.
* **Spatio-Temporal WebGL Trajectory Pipeline:** Renders historical and deep-sea depth anomalies smoothly on a 3D canvas map.
* **Multi-Variable Analytics Interface:** Provides clear, side-by-side metric charts monitoring ocean temperature vs. salinity levels.
